# Modern & Aesthetic Login Page

A modern, responsive, glassmorphic login and sign-up web page project built from scratch using HTML5, CSS3, and JavaScript.

## 🚀 Features

- **Modern Glassmorphism UI**: High-end dark theme with subtle glowing background ambient orbs and blurred glass card.
- **Show/Hide Password**: Toggle password visibility with an eye icon.
- **Interactive Sign In & Sign Up Modes**: Seamlessly switch between Sign In and Sign Up views without reloading the page.
- **Forgot Password Modal**: Interactive modal popup to request password reset emails.
- **Form Validation & Real-time Feedback**: Clean error indicators and animated messages.
- **Toast Notifications**: Built-in notification toasts for user actions (Success, Info, Error).
- **Responsive Design**: Looks awesome on desktop, tablet, and mobile devices.
- **Pure Vanilla Tech Stack**: Built with separate HTML, CSS, and JS files—no frameworks, databases, or complex setup required.

## 📂 Project Structure

```
modern-login-page/
│
├── index.html      # Main HTML layout & markup
├── styles.css      # Custom CSS design system, glassmorphism & responsive styles
├── script.js      # Interactive JavaScript (validation, password toggle, modal, toasts)
└── README.md       # Project documentation & guide
```

## 💻 How to View & Preview

1. Open the project folder `modern-login-page` on your Desktop.
2. Double-click **`index.html`** to open and preview the web page directly in your favorite web browser (Google Chrome, Edge, Firefox, Safari).
3. Test out the interactive features:
   - Click the **Eye icon** in the password field to show/hide the password.
   - Click **"Sign Up"** at the bottom to transition to the account creation form.
   - Click **"Forgot password?"** to test the interactive reset password popup modal.
   - Click **"Sign In"** to see front-end validation and animated toast feedback!
